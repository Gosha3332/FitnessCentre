# FitnessCentre

|Выбор нехнологии<br>
|>Был выбран C# на базе ASP.NET за предположенность к написанию backend части, нормальную реализацию парадигмы ООП, наличие встроенного DI контейнера, компилируемые языки (насколько я знаю), работают быстрее.<br>

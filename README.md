# FitnessCentre

|Выбор нехнологии
|>Был выбран C# на базе ASP.NET за предположенность к написанию backend части, нормальную реализацию парадигмы ООП, наличие встроенного DI контейнера, компилируемые языки (насколько я знаю), работают быстрее.
|>Был выбран фремворк для работы с бд EntityFramework, так как он позволяет просто разворачивать таблицы без прямого использования sql запросов, просто создав таблицы и пробросив в модели контекст.
